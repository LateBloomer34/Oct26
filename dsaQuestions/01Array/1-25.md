Level 1 — Array fundamentals (1–25)
Focus: loops, indexing, conditions, and basic calculations.


☐ 1. Print All Array Elements
Problem: Return all elements in their original order.
Input:  arr = [4, 2, 7, 1]
Output: [4, 2, 7, 1]

☐ 2. Print Elements on Separate Lines
Problem: Output each element on a separate line.
Input:  arr = [5, 8, 3]
Output: 5
        8
        3

☐ 3. Print an Array in Reverse Order
Problem: Return elements from last to first without modifying the input.
Input:  arr = [1, 2, 3, 4]
Output: [4, 3, 2, 1]

☐ 4. Sum of Array Elements
Problem: Return the sum of all elements.
Input:  arr = [1, 2, 3, 4]
Output: 10

☐ 5. Average of Array Elements
Problem: Return the average of the elements.
Input:  arr = [2, 4, 6, 8]
Output: 5.0

☐ 6. Find the Maximum Element
Problem: Return the largest element.
Input:  arr = [3, 9, 2, 7]
Output: 9

☐ 7. Find the Minimum Element
Problem: Return the smallest element.
Input:  arr = [3, 9, 2, 7]
Output: 2

☐ 8. Count Even Numbers
Problem: Count elements divisible by 2.
Input:  arr = [1, 2, 4, 7, 8]
Output: 3

☐ 9. Count Odd Numbers
Problem: Count odd elements.
Input:  arr = [1, 2, 4, 7, 8]
Output: 2

☐ 10. Count Positive, Negative, and Zero
Problem: Count each category separately.
Input:  arr = [-2, 0, 4, -1, 5, 0]
Output: positive = 2, negative = 2, zero = 2

☐ 11. First Array Element
Problem: Return the first element. Assume the array is non-empty.
Input:  arr = [8, 3, 5]
Output: 8

☐ 12. Last Array Element
Problem: Return the last element. Assume the array is non-empty.
Input:  arr = [8, 3, 5]
Output: 5

☐ 13. Elements at Even Indices
Problem: Return elements at indices 0, 2, 4, ...
Input:  arr = [10, 20, 30, 40, 50]
Output: [10, 30, 50]

☐ 14. Elements at Odd Indices
Problem: Return elements at indices 1, 3, 5, ...
Input:  arr = [10, 20, 30, 40, 50]
Output: [20, 40]

☐ 15. Linear Search
Problem: Return the index of target, or -1 if absent.
Input:  arr = [4, 7, 2, 9], target = 2
Output: 2

☐ 16. Check Whether an Element Exists
Problem: Return true if target occurs in the array.
Input:  arr = [3, 6, 9], target = 6
Output: true

☐ 17. Count Occurrences of a Target
Problem: Count how many times target occurs.
Input:  arr = [2, 3, 2, 5, 2], target = 2
Output: 3

☐ 18. Sum of Elements at Even Indices
Problem: Sum elements at indices 0, 2, 4, ...
Input:  arr = [1, 2, 3, 4, 5]
Output: 9

☐ 19. Sum of Elements at Odd Indices
Problem: Sum elements at indices 1, 3, 5, ...
Input:  arr = [1, 2, 3, 4, 5]
Output: 6

☐ 20. Find Minimum and Maximum Together
Problem: Return both values in one traversal.
Input:  arr = [5, -2, 11, 4]
Output: [-2, 11]

☐ 21. Elements Greater Than X
Problem: Return all elements greater than x in original order.
Input:  arr = [1, 7, 3, 9, 5], x = 5
Output: [7, 9]

☐ 22. Elements Smaller Than X
Problem: Return all elements smaller than x.
Input:  arr = [1, 7, 3, 9, 5], x = 5
Output: [1, 3]

☐ 23. Count Elements Divisible by K
Problem: Count elements divisible by nonzero k.
Input:  arr = [2, 4, 5, 8, 10], k = 2
Output: 4

☐ 24. Product of Array Elements
Problem: Return the product. Assume the result fits the chosen type.
Input:  arr = [2, 3, 4]
Output: 24

☐ 25. Copy an Array
Problem: Return a separate array containing the same elements.
Input:  arr = [5, 1, 8]
Output: [5, 1, 8]
