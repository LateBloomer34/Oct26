Level 2 — Basic array manipulation


☐ 26. Reverse an Array In Place
Input:  arr = [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]

☐ 27. Swap First and Last Elements
Input:  arr = [2, 4, 6, 8]
Output: [8, 4, 6, 2]

☐ 28. Swap Elements at Two Indices
Input:  arr = [10, 20, 30, 40], i = 1, j = 3
Output: [10, 40, 30, 20]

☐ 29. Replace Negative Elements with Zero
Input:  arr = [-2, 3, -1, 5]
Output: [0, 3, 0, 5]

☐ 30. Replace Zeros with Ones
Input:  arr = [0, 2, 0, 4]
Output: [1, 2, 1, 4]

☐ 31. Multiply Every Element by X
Input:  arr = [1, 2, 3], x = 3
Output: [3, 6, 9]

☐ 32. Add X to Every Element
Input:  arr = [1, 2, 3], x = 5
Output: [6, 7, 8]

☐ 33. Square Every Element
Input:  arr = [-2, 3, 4]
Output: [4, 9, 16]

☐ 34. Cube Every Element
Input:  arr = [2, -3, 4]
Output: [8, -27, 64]

☐ 35. Extract Even Elements
Input:  arr = [1, 2, 3, 4, 6]
Output: [2, 4, 6]

☐ 36. Extract Odd Elements
Input:  arr = [1, 2, 3, 4, 6]
Output: [1, 3]

☐ 37. Separate Positive and Negative Elements
Problem: Return positive and negative values in separate arrays; zeros are omitted.
Input:  arr = [-2, 3, 0, -1, 5]
Output: positive = [3, 5], negative = [-2, -1]

☐ 38. Move Zeros to the End
Problem: Preserve the order of nonzero elements.
Input:  arr = [0, 1, 0, 3, 12]
Output: [1, 3, 12, 0, 0]

☐ 39. Move Negative Elements to the Beginning
Problem: Negative values must precede nonnegative values.
Input:  arr = [3, -1, 0, -5, 2]
Output: [-1, -5, 3, 0, 2]
Note: Any arrangement satisfying the partition is acceptable.

☐ 40. Move Even Elements Before Odd Elements
Input:  arr = [3, 2, 5, 4]
Output: [2, 4, 3, 5]
Note: Any valid partition is acceptable.

☐ 41. Swap Adjacent Pairs
Problem: Swap indices (0,1), (2,3), and so on.
Input:  arr = [1, 2, 3, 4, 5]
Output: [2, 1, 4, 3, 5]

☐ 42. Rotate Left by One
Input:  arr = [1, 2, 3, 4, 5]
Output: [2, 3, 4, 5, 1]

☐ 43. Rotate Right by One
Input:  arr = [1, 2, 3, 4, 5]
Output: [5, 1, 2, 3, 4]

☐ 44. Rotate Left by K Positions
Input:  arr = [1, 2, 3, 4, 5], k = 2
Output: [3, 4, 5, 1, 2]

☐ 45. Rotate Right by K Positions
Input:  arr = [1, 2, 3, 4, 5], k = 2
Output: [4, 5, 1, 2, 3]

☐ 46. Insert an Element at an Index
Input:  arr = [1, 2, 4, 5], index = 2, value = 3
Output: [1, 2, 3, 4, 5]

☐ 47. Delete an Element at an Index
Input:  arr = [10, 20, 30, 40], index = 1
Output: [10, 30, 40]

☐ 48. Remove the First Occurrence of a Value
Input:  arr = [2, 5, 2, 7], value = 2
Output: [5, 2, 7]

☐ 49. Remove All Occurrences of a Value
Input:  arr = [2, 5, 2, 7, 2], value = 2
Output: [5, 7]

☐ 50. Remove Consecutive Duplicates from a Sorted Array
Input:  arr = [1, 1, 2, 2, 2, 3, 4, 4]
Output: [1, 2, 3, 4]
